# SAKURA 18+

Telegram bot + web admin panel.

## Запуск
1. Установить Python 3.11+.
2. `pip install -r requirements.txt`
3. Скопировать `.env.example` в `.env`.
4. В `.env` указать `BOT_TOKEN`.
5. `python main.py` или `START.bat`.
6. Админка: `http://127.0.0.1:8000/login`.

По умолчанию логин `admin`, пароль `1324`; их можно изменить через `.env`.

## История пользователя
При открытии пользователя админка показывает:
- входящие и исходящие сообщения;
- Telegram message ID, тип и время;
- все зарегистрированные действия;
- полученные и отправленные фотографии;
- просмотр фотографии в браузере;
- скачивание оригинального сохранённого файла;
- подпись к фото;
- изменение баланса с записью действия.

Старая база `sakura18.db` не требует удаления: таблицы для истории создаются автоматически.
